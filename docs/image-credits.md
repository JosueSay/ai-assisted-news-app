# Creditos de imagenes

Estado: pendiente de seleccion de fotografias reales.

La implementacion actual usa placeholders locales honestos con el texto
"Imagen no disponible". No se descargaron fotografias ni se inventaron URLs,
autores o licencias.

Antes de considerar completa la direccion fotografica hay que reemplazar cada
placeholder del dataset por un asset local con:

- archivo;
- articulo asociado;
- URL de origen;
- autor;
- licencia o condiciones comprobadas;
- fecha de consulta;
- nota de uso ilustrativo.

Las rutas de imagen del dataset permanecen en `null` hasta que esos assets
esten verificados.
