# Servicios backend futuros

Espacio reservado para los demás servicios del backend.

Cada servicio nuevo debe tener una carpeta propia con:

- `README.md` con propósito, configuración, endpoints y forma de ejecución;
- código aislado del servicio;
- `tests/` con sus pruebas unitarias y de integración;
- Dockerfile propio únicamente si se desplegará como proceso independiente.
